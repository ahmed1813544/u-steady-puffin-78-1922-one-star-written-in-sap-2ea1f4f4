Entry for the [make.fun bounty "One Star, Written in Sap"](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4): a single one-line, one-star review written by a houseplant about its human owner.

`main.py` (Python 3.13, stdlib only) writes the review to the output path — it honours `MAKEFUN_OUTPUT_DIR` when set, otherwise `/output/entry.txt` — and asserts the 1–279 character gate before writing. The program is deterministic: two runs produce byte-identical output.

Run it:

```sh
python3 main.py
```
